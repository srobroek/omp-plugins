toolchain rules, read on demand via `rule://<name>`:

- `toolchain-stack-defaults` — package managers, mise/just/moon, adding deps.
- `toolchain-frontend` — frontend framework or state library choice.
- `toolchain-infrastructure` — Terraform, CDK, Kubernetes, Helm.
- `toolchain-languages` — per-language library and test/lint picks.
- `toolchain-quality-observability` — logging, tracing, scanners.
- `toolchain-tools-scripts` — `scripts/`, `tools/`, task-runner files.
- `toolchain-pragmatic` — what produced artifacts may contain.
- `toolchain-asset-ownership` — where OMP config and plugins live.

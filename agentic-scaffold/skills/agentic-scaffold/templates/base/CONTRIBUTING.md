# Contributing

## Before you start

Open a discussion for substantial changes before writing code. Keep each pull request focused and open it as a draft until the change is ready for review.

## Development

Run `just check` before requesting review. The `gate` job in CI is required and must pass before merge.

## Commits

Use Conventional Commits, such as `feat: add export` or `fix: handle empty input`.

## Pull requests

Explain why the change is needed, what changed, and how you verified it. Resolve review comments before requesting a final review.

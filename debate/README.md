# debate

Before committing, stress-test an architectural decision, technology choice, or feature proposal from both sides.

Specified questions get a direct two-sided answer. When warranted or requested, the skill adds deeper research, independent critique, and a saved report.

## Skills

| Name | When |
|------|------|
| `debate` | Two-sided analysis before committing to a decision |
| `grilling` | Interview the user in numbered frontier rounds until every branch of a decision is settled; `debate` routes deeper interviews here |
| `to-questionnaire` | User-invoked: turn a decision the user cannot answer alone into a questionnaire for one other person, written to a named path or `~/tmp` |

`grilling` and `to-questionnaire` are vendored in modified form from
[mattpocock/skills](https://github.com/mattpocock/skills) under the MIT licence. Each skill
directory carries the licence text and a NOTICE listing the changes.

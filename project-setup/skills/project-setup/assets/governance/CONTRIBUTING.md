# Contributing

## Before opening a change

Read `AGENTS.md` and the relevant files under `docs/agents/`. Use the repository's existing
member path and language recipe. Do not add a new orchestration layer.

## Pull requests

Explain the user-visible behavior, identify affected member paths, and record the verification
command and result. Keep unrelated formatting or generated-file changes out of the change.

Do not include credentials, tokens, or private data in commits, issues, or pull requests.

# research

Exploration and reasoning agents, plus Repomix bulk-pack recipes.

## Agents

| Name | Role | When |
|------|------|------|
| `explorer` | `@task` | Map files and runtime paths for a bounded question |
| `reasoner` | `@plan` | Resolve one architecture or policy question without implementing |

## Rules

- `research-index` (always-apply)
- `research-repomix-recipes` — pack many files at once with Repomix

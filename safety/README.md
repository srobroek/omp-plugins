# safety

Defence-in-depth advisories and small extension guards.

## Rules (TTSR)

- `srobroek-attribution-guard`
- `srobroek-bash-indirection-guard`
- `srobroek-git-force-push-advisory`
- `srobroek-package-investigate`
- `srobroek-remote-exec-guard`
- `srobroek-sudo-destructive-advisory`

## Extensions

- `close-keywords` — rewrite `gh pr create|edit --body` so close-keywords apply to every issue in a list
- `quality-edit-advisory` — after enough edits, suggest targeted language checks

`srobroek-package-investigate` replaced the `package-investigate` extension so the vet fires before the install, not after the result.

## What did not survive from the legacy hooks

- **commit-msg rewrite** (`hooks-close-keywords` pre-commit `commit-msg` stage). OMP has no git commit-msg hook runtime. Only the `gh pr` path is ported (as a `tool_call` input rewrite).
- **PreToolUse `additionalContext`**. OMP cannot inject pre-tool advice without blocking. `quality-edit-advisory` prepends a reminder on `tool_result`. `close-keywords` rewrites the command rather than advising. Package-add advice is now the `srobroek-package-investigate` TTSR rule.
- **pre-commit hook-installed probe** (`git rev-parse --git-path hooks` + "generated by pre-commit"). Dropped to keep the edit-path handler free of subprocesses. Coverage is inferred from `.pre-commit-config.y*ml` checker names only.

# Delegation Choreography

TRIGGER
+ Non-trivial repository discovery, implementation, debugging, or verification work
- A direct answer or one exact edit with no discovery or callsite search → handle directly

## Rules

MUST Delegate non-trivial work to task agents.
MUST When editing code, change only prose that explains or specifies the changed code.

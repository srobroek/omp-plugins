This `git push` names `main` or a legacy default branch as its destination. Confirm that publishing there is intentional.

The rule matches bash arguments as text and never blocks the command (`interruptMode: never`). It cannot inspect the repository, branch, remote, or server protection. It classifies spelled-out destinations such as `origin main`, `HEAD:main`, `refs/heads/main`, `:main`, and `+HEAD:main`, including pushes executed through command substitution, a shell `-c` argument, or `mise exec --`. Bare pushes, remote names, option values, and quoted argument data are left alone. Heredoc bodies are scanned because they can feed a shell.
